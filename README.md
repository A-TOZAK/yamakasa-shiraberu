# 飯塚山笠を調べよう（4年社会 単元の進め方）

4年社会「地域で受けつがれてきたもの」で、子どもが自分で調べる単元の進め方をまとめたページです。

- 公開URL：https://a-tozak.github.io/yamakasa-shiraberu/
- `index.html`：学習の進め方（5つの段階）、調べるときのくり返し、調べる先、使う紙
- `gemini.html`：Gemini Notebookを調べ方の相談相手にする作り方
- `files/`：配る紙（PDF・xlsx）と、Gemini Notebookに入れる単元の手引き
- `img/`：千早リコ（School Stock素材スタジオの架空の作家）の絵。AIで生成し、検品したもの

直すときは `_build/content.py`（文）か `_build/build.py`（形）を直して `python3 _build/build.py`。

子どもの名前と学校の中のことは入れていません。© School Stock
